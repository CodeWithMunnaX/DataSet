# 📊 DataSet

Practice datasets and SQL exercises for learning data analysis.

## 📁 Files

| File | Description |
|------|-------------|
| [`datasets/customer.csv`](datasets/customer.csv) | 1000 e-commerce orders (2024–2025) |
| [`datasets/cricket_dataset.csv`](datasets/cricket_dataset.csv) | 1000 cricket player match records |
| [`sql/customer.sql`](sql/customer.sql) | SQL operators practice — questions + solutions |

## 🧑‍💻 SQL Practice

`customer.sql` covers: **Comparison**, **Logical** (`AND` `OR` `NOT`), **BETWEEN**, **IN / NOT IN** and **LIKE**.

**How to use:** Open `customer.sql` in SQL Server, update the `BULK INSERT` path to your `customer.csv`, and run.
